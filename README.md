# 🛡️ FocusShield — Firefox Site Blocker Extension

**FocusShield** is a modern, minimalist, and sleek browser extension for Firefox built with **WebExtension Manifest V3**. It helps you stay productive by restricting access to distracting websites, offering customizable schedule periods, focus timers, motivational quote banners, and an anti-cheat typing challenge.

---

## ✨ Features

- 🛡️ **Dynamic Website Blocking**: Add or remove websites dynamically from your personal blocklist without touching code.
- 🔒 **Anti-Cheat Typing Challenge**: Require typing a custom friction phrase before turning off protection.
- 📅 **Scheduled Focus Hours**: Automatically enforce site blocking during specific hours (e.g. 09:00 to 17:00) and active weekdays (Mon–Sun).
- ⏱️ **Pomodoro & Focus Timers**: Set custom focus session durations (25 min, 45 min, 60 min) for deep work sprints.
- 💬 **Custom Motivational Quotes**: Display your personal goals or inspirational quotes on the blocked landing screen.
- 🎨 **Sleek Modern UI**: Premium dark mode glassmorphic interface with responsive controls.
- ⚡ **Auto Tab Interception**: Instantly scans and redirects currently open tabs when protection activates.
